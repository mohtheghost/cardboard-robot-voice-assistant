# Archived firmware versions

Every prototype `.ino` from the development folder, unchanged except that the WiFi name,
WiFi password and server IP were replaced by placeholders. File names are the original
download names: a `_N` suffix is a browser "download again" copy, **not** a version number.
Order them by the date column. `docs/history.md` tells the story; this is the index.

Status meanings: **milestone** = worth reading, **intermediate** = a step on the way,
**broken** = does not compile or is not code, **duplicate** = identical to another file,
**test** = a hardware test utility.
